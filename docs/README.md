# Documentation index

Use this directory for written guides, diagrams and reusable investigation references.

| Folder / file | Tag | Purpose |
|---|---|---|
| [assets/](assets/) | `Visuals` | SVG diagrams used in the top-level README to explain the workflow, evidence model and safety boundaries. |
| [references/](references/) | `Reference guides` | Reusable report template, investigation checklist and beginner-contribution playbook. |
| [installation.md](installation.md) | `Setup guide` | Detailed installation, CLI usage, public GitHub support, optional AI setup and test instructions. |

## Start here

- New to the project? Read the [repository homepage](../README.md).
- Want to install and run the CLI? Follow the [installation guide](installation.md).
- Need a reusable investigation process? Use the [investigation checklist](references/investigation-checklist.md).
- Need a report structure? Start from the [analysis output template](references/analysis-output-template.md).
- Looking for a safe beginner task? Read the [beginner issue playbook](references/beginner-issue-playbook.md).

The project icon/brand hero remains in the top-level `assets/` folder because the agent metadata references it directly. The illustrations for documentation live here so brand assets and documentation assets are separated.
